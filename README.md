# Tic-tac-toe

Jeu de morpion à deux joueurs dans le navigateur.

**[Jouer](https://aristidebamenou.github.io/tic-tac-toe/)**

## Ce que j'ai fait
- Saisie du nom des deux joueurs, bouton pour lancer et relancer la partie.
- Détection de la victoire et du match nul, avec affichage du résultat.
- Architecture en classes, chacune avec un seul rôle : `Player`, `Cell`, `GameBoard`, `GameController` (règles du jeu) et `ScreenController` (affichage).
- Logique d'abord écrite pour la console, puis branchée sur l'interface.

## Stack
HTML · CSS · JavaScript · Bootstrap

## Lancer en local
Ouvrir `index.html` dans un navigateur.
